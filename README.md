# University Markup & Scripting Language

A collection of my academic coursework, practical assignments, classroom
exercises, and personal practice related to Markup and Scripting Language
and basic web development.

This repository was created to keep my university learning work organized
and to maintain a record of my progress while learning web technologies.

---

## About This Repository

The repository contains practical exercises developed while learning and
practicing:

- HTML
- CSS
- JavaScript
- Responsive Web Design
- Web Page Layout
- HTML Forms
- Navigation Menus
- CSS Animations
- CSS Hover Effects
- DOM Manipulation
- Basic Client-Side Interaction
- iframe and embedded web content

Most of the work consists of small academic exercises and assignments
rather than large software projects. The main focus is on understanding
the fundamentals and applying them through practical coding.
